RFC 4180 inline-errata, "Common Format and MIME Type for Comma-Separated Values (CSV) Files", October 2005

Source of RFC: IETF - NON WORKING GROUP

Updated by: RFC7111

Area assignment: app

Status:
Verified

Editorial
Reported By:

Verified by:
Barry Leiba
Date Verified:
2019-05-01

Section 5, 6 says: 

Section 5: 
  "aaa","bbb","ccc" CRLF
Section 6: 
  "aaa","b CRLF
  bb","ccc" CRLF
  zzz,yyy,xxx

It should say:

Section 5:
  "aaa","bbb","ccc"CRLF
Section 6:
  "aaa","b CRLF
  bb","ccc"CRLF
  zzz,yyy,xxx

Notes:

As implied in the ABNF grammar, escaped (quoted) fields may not be followed by a space.
The corrected text removes those spaces from the examples, making them syntactically correct.
