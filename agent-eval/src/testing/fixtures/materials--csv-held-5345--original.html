Section 2 says: 

6.  Fields containing line breaks (CRLF), double quotes, and commas 
should be enclosed in double-quotes.

It should say:

6.  Fields containing line breaks (CRLF), double quotes, and commas 
must be enclosed in double-quotes.

Notes:

CSV is clearly unparsable if commas are not enclosed in double quotes.
