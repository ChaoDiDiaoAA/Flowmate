# 单人开发环境、密钥、备份与安全教程

## 目标

完成后，你应拥有：可运行的开发工具、已初始化的 Git、本地密钥隔离、可恢复备份，以及不包含真实数据的项目目录。

## 1. 安装工具

在 Windows PowerShell 中逐条运行。已经安装的工具只执行版本检查。

### Git

```powershell
winget install --id Git.Git -e
git --version
```

正确结果包含 `git version`。如果系统找不到 `git`，关闭 PowerShell 后重新打开再检查。

### Node.js LTS

```powershell
winget install --id OpenJS.NodeJS.LTS -e
node --version
npm --version
```

两个命令都必须输出版本号。

Node.js LTS 会同时安装 npm，不需要额外安装其他包管理器。再次确认：

```powershell
npm --version
```

### Obsidian

```powershell
winget install --id Obsidian.Obsidian -e
```

👤 打开 Obsidian，确认能够创建一个空 Vault。此时不要导入真实发票。

## 2. 固定工作目录

项目目录固定为：

```text
D:\code\agent-learn\agent\Flowmate
```

每次运行项目命令前先执行：

```powershell
Set-Location -LiteralPath 'D:\code\agent-learn\agent\Flowmate'
Get-Location
```

正确结果必须以 `Flowmate` 结尾。

## 3. 初始化 Git

当前目录最初可能不是 Git 仓库。检查：

```powershell
git status
```

如果提示“not a git repository”，执行：

```powershell
git init
git branch -M main
```

不要连接远程仓库，直到 `.gitignore` 已建立并通过密钥扫描。

## 4. 建立安全目录规则

项目代码目录只允许保存：

```text
源码
测试
Mock fixture
脱敏且获准进入仓库的极少量样例
文档
不含密钥的配置示例
```

以下内容保存在项目目录之外的加密数据目录：

```text
真实发票
供应商和 PO 导出
生产截图
账号材料
人工正确答案
最终验收集
数据库生产备份
```

推荐本机数据根目录使用：

```text
D:\code\agent-learn\agent\Flowmate\FlowmateData
```

该目录必须位于启用 BitLocker 或等效磁盘加密的磁盘，并且不能被 Git 跟踪。

## 5. `.gitignore` 最低要求

阶段 A 创建工程时，`.gitignore` 至少包含：

```gitignore
node_modules/
dist/
build/
coverage/
playwright-report/
test-results/
.env
.env.*
!.env.example
*.db
*.db-shm
*.db-wal
data/raw/
data/private/
secrets/
*.pem
*.key
auth.json
```

每次提交前执行：

```powershell
git status --short
git diff --cached
```

👤 如果输出包含发票、密码、Token、Cookie、`.env` 或生产截图，停止提交。

## 6. 密钥使用规则

开发阶段只在本机 `.env.local` 或受控 Secret Store 保存密钥。仓库只提交 `.env.example`：

```dotenv
FLOWMATE_MODEL_PROVIDER=
FLOWMATE_MODEL_ID=
FLOWMATE_LLM_API_KEY=
```

不要在 `.env.example` 中填入真实值。

代码只能读取环境变量并把密钥注入 Pi ModelRuntime，不能把密钥传给 Renderer、Prompt 或 Tool 参数。

## 7. 三级备份

最低备份规则：

```text
代码：Git 历史
运行数据：SQLite 在线备份或停机副本
真实数据资产：加密数据盘 + 第二份加密备份
```

每个阶段完成时创建一份恢复记录：

```text
备份日期
代码提交 ID
数据库文件位置
数据集版本
应用版本
恢复步骤是否演练成功
```

只有“复制了文件”不算完成备份；必须至少恢复一次并打开验证。

## 8. AI 可以做和不能做的事

🤖 AI 可以：

- 修改项目源码和测试；
- 生成 Mock 数据；
- 写导入、校验、导出工具；
- 分析脱敏后的错误日志；
- 帮你生成数据申请清单。

AI 不应：

- 读取完整生产密码；
- 把真实发票上传到未经批准的模型或服务；
- 自动确认生产提交；
- 绕过验证码、MFA、扫码；
- 删除唯一备份；
- 未经检查执行数据库结构破坏性操作。
