# C 真实 07B2B 测试环境集成计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 使用获准的测试账号，在 07B2B 测试或沙箱环境完成登录、导航、填表、测试提交、状态查询和人工接管。

**Architecture:** 优先使用正式 API；没有 API 时使用 Playwright 稳定 Locator；视觉 Computer Use 仅作人工辅助。凭证通过 accountProfileId 注入，Agent 不接触原始密码。

**Tech Stack:** TypeScript、Playwright、CredentialManager、SQLite、截图审计、Pi Runtime。

**Spec:** [B 阶段](B_真实发票与OCR手把手开发教程.md)、[安全规则](02_单人开发环境_密钥备份与安全.md)

## Global Constraints

- 必须获得平台测试环境和自动化访问许可；
- 不绕过验证码、MFA、扫码、USB Key 或安全限制；
- API > Playwright/CDP > 视觉辅助；
- Agent 只看到 accountProfileId；
- 生产账号和生产写入在本阶段禁止；
- Submit 超时必须进入 UNKNOWN_COMMIT_STATE 并查询状态；
- 所有关键页面保存截图 hash 和受控文件引用。

## Task C3：固定 B2B Contract

**Files:**

- Modify: `packages/adapters/src/contracts.ts`
- Create: `packages/adapters/test/b2b-contract.test.ts`

```ts
export interface B2BConnector {
  login(accountProfileId: string): Promise<LoginResult>;
  preview(input: Submission): Promise<SubmissionPreview>;
```

## Task C8：确认是否需要独立 Runtime 子进程

先运行 2 小时连续测试和 50 个任务：

```powershell

```

如果需要，子进程只负责：Pi Hosting、命令映射、事件映射、健康检查和崩溃重启；继续复用 Pi 的 Runtime 能力。
