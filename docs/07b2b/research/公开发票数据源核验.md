# P0 公开发票数据源核验

> 核验日期：2026-08-26  
> 用途：选择 P0 公开发票 Smoke Test 数据，不代表最终企业验收数据

## 结论

P0 Smoke Test 选用：

```text
Voxel51/high-quality-invoice-images-for-ocr
```

理由：

- 数据集明确包含发票图片，而不是论文；
- Hugging Face Dataset Card 声明共有 8,181 张合成发票图片；
- 其中 1,489 张包含结构化 JSON 和 OCR 文本；
- Hugging Face API 的 license 字段为 `odbl`；
- 数据集公开、非 gated、非 private；
- 原始 Kaggle API 返回 `Database: Open Database, Contents: Database Contents`；
- 可以只下载一张图片和对应标注，不需要下载约 2.39 GB 全量数据。

来源：[Hugging Face Dataset Card](https://huggingface.co/datasets/Voxel51/high-quality-invoice-images-for-ocr)、[Hugging Face Dataset API](https://huggingface.co/api/datasets/Voxel51/high-quality-invoice-images-for-ocr)、[Kaggle 原始数据集](https://www.kaggle.com/datasets/osamahosamabdellatif/high-quality-invoice-images-for-ocr)。

## P0 固定样本

P0 计划使用数据集中的一个已标注合成发票：

```text
image: data/batch1-0494.jpg
annotation source: samples.json
```

该条目的 `samples.json` 记录包含：

- invoice number；
- invoice date；
- seller/client；
- line items；
- tax/total；
- OCR text。

本机验证结果：

```text
文件大小：216316 bytes
SHA-256：2c4cd305a510de6ddb573e81067e5ed8a6af4fcaf0a7fc678f52f914702e6a60
```

MinerU 云端无法直接访问 Hugging Face URL，返回 `-60023 regional regulations`。先用 Windows PowerShell `Invoke-WebRequest` 保存公开原始图片，再把本地文件路径交给包装后的 MinerU MCP，可以成功解析。

MinerU 解析结果包含：

```text
Invoice no: 84652373
Date of issue: 02/23/2021
Seller: Nguyen-Roach
Client: Clark-Foster
Total: 232.95
```

因此 P0 的强制数据流是：

```text
OpenCLI发现
→ PowerShell下载原始文件
→ SHA-256
→ Raw Archive
→ 本地文件路径传给MinerU
```

不能把 Hugging Face URL 直接交给 MinerU，也不能只保存 MinerU 派生 Markdown。

样本含逼真的合成姓名、地址、Tax ID 和 IBAN。Source Policy 必须标记 `synthetic=true` 和 `contains_synthetic_identifiers=true`，不得误认为真实个人数据，也不得用于企业真实准确率验收。

## 被隔离的候选

### mychen76/invoices-and-receipts_ocr_v1

- 具有图片、parsed data 和 raw data；
- 公开、非 gated；
- Hugging Face API 没有明确 license；
- Dataset Card 标记需要补充信息。

处理：`QUARANTINED_LICENSE`，不进入 P0 Release。

来源：[Hugging Face Dataset API](https://huggingface.co/api/datasets/mychen76/invoices-and-receipts_ocr_v1)、[Dataset Card](https://huggingface.co/datasets/mychen76/invoices-and-receipts_ocr_v1)。

### GokulRajaR/invoice-ocr-json

- 包含发票图像和自动生成 JSON；
- Hugging Face API 没有明确 license；
- Dataset Card 使用“CC BY-SA 4.0 或原始数据集适用许可”的不确定表述；
- 标注由模型自动生成，仅有限人工抽查。

处理：`QUARANTINED_LICENSE`，不作为 Golden Label。

来源：[Hugging Face Dataset API](https://huggingface.co/api/datasets/GokulRajaR/invoice-ocr-json)、[Dataset Card](https://huggingface.co/datasets/GokulRajaR/invoice-ocr-json)。

### longmaodata/Invoice-annotation

Hugging Face API 返回 401，不能作为 P0 自动公开数据源。

处理：不采集。

## 使用限制

- 该数据集是英文合成发票，不代表中国增值税发票；
- 只能验证采集、原始保存、MinerU、去重、Policy、Obsidian 和 Dataset 发布流程；
- 不能替代企业脱敏历史发票；
- 不能用于证明 07B2B 生产准确率；
- 不能进入最终 acceptance split；
- P2 必须使用企业内部真实分布数据重新评估。
