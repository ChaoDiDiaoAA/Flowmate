# 07b2b 文档导航

本目录记录 Flowmate 的目标、计划、研究和证据。阅读和执行顺序是：

```text
specs（目标与边界） → plans（实施步骤） → evidence（验证结果）
```

## 目录

- **Target Specs** — [`specs/`](specs/)：产品总目标和 P0 目标方案；定义职责、接口、约束与验收边界。
- **Implementation Plans** — [`plans/`](plans/)：经批准后可执行的分阶段计划。
- **Research and Evidence** — [`research/`](research/) 与 [`evidence/`](evidence/)：来源核验、Spike、失败记录和可复现验证结果。

入口建议先读 [`specs/P0_Obsidian数据库目标方案.md`](specs/P0_Obsidian数据库目标方案.md)，再读 [`plans/P0_Obsidian数据库实施计划.md`](plans/P0_Obsidian数据库实施计划.md)。

## 教程状态

根目录下的 `A_`–`G_`、`DATA-01`–`DATA-03` 等 Superpowers 之前编写的手把手教程保留作 draft/archive 参考，不能作为当前执行入口，也不能覆盖最新 spec、plan 或 evidence。若教程与批准后的计划冲突，以 spec → plan → evidence 链为准。
