# 发票字段整理
1. 先查看当前冻结的材料与候选，使用现有发票证据读取工具取得需要核对的内容，不把通用文件读取直接当成业务合法来源。
2. 需要字段规则时读取references/field-rules.md；保留来源工具返回的完整版本，不自行拼接或猜测source引用。
3. 逐字段区分有证据的值、缺失、无法辨认、不适用和冲突；不足两个有依据的替代值时，不构造ambiguous来代替不知道。
4. 规范化使用当前normalize_invoice_values；来源检查和候选验证使用现有工具。根据真实诊断说明未解决问题，不将工具拒绝描述为已通过。
